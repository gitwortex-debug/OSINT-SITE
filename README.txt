OSINT RUSSIAN MILITARY — демонстрационный комплект

Файлы:
- index.html — сайт с карточками публикаций, в которых видео показывается сверху, а заголовок и описание находятся снизу.
- content/posts.json — демонстрационные публикации.

Видеоссылки:
- Прямой URL к MP4 — вставляется в поле "video".
- YouTube URL — вставляется в поле "video", сайт попытается встроить плеер.
- Если поле "video" пустое, покажется заглушка.

Для публикации:
1. Меняйте записи в content/posts.json или подключите CMS позже.
2. В каждой записи указывайте category: "news" или "geo", label, date, title, description, video, source, sourceLabel.
3. Не загружайте большие видеофайлы непосредственно в GitHub; лучше использовать видеохостинг и ссылку на видео.
4. Перед публикацией проверяйте права на видео и достоверность источников.

Важно: пример MP4 на сайте — только демонстрационный ролик, замените его своей подходящей ссылкой.
